# Identity Trust Assessment

A five-dimension trust assessment framework for patient identity resolution in hyper-diverse health information exchanges.

## Contents

- Malafi.ipynb — Full prototype: population generators, validators, six comparison models, and the evaluation pipeline.

## Reproducing the results

Open the notebook in Jupyter and run all cells top to bottom. Population generators use fixed random seeds (42 for the Gulf population; 55555 for the Australian population), so results are reproducible.
